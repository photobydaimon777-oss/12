Запуск из `/workspace/12`: `python3 -m http.server 8000 --bind 0.0.0.0`.

- `portobello-data.js`: требования Портобелло, сверены с PDF `sources/portobello.pdf`; ссылка на страницу источника в карточке.

- Проект 111, Вива Гифтс, Артэ Гифтс, Хеппи Гифтс: ссылки сохранены, загрузка вернула HTTP 403. Параметры не придуманы, доступность методов не подтверждена.

Нет данных в источнике — показано явно. Flex не приравнивается к шелкотермотрансферу, специальные УФ-эффекты — к обычной УФ-печати. В усреднённой базе для смоляных наклеек вылеты 2,5 и 3 мм противоречат друг другу; расхождение показано для уточнения. Отсутствующие расшифровки сносок не восстановлены догадками.

Дополнительно подключены Адъютант, Океан Гифтс (с разбивкой по изделиям), Гекса, Роял Принт — из сообщений пользователя; GALA POLYGRAPH — из двух изображений; Мидоушен — только список кодов персонализации без числовых требований. Значки с эмалью оставлены без поставщика по решению пользователя. Ориентиры по Flex на основе Салитекс явно отмечены как очень усреднённые, не как спецификация поставщика. Ссылка Топ каталога на SharePoint сохранена, загрузка вернула HTTP 403.

Сопоставляются параметры выбранного метода; отсутствующие значения не подменяются чужими. Специфические варианты Океана сопоставлены с базовым методом нашей базы. Размеры гравировки 150 × 150 и 1500 × 1500 мм в текстах Океана/Гексы оставлены как противоречие для уточнения. Для джибитсов отдельной спецификации пока нет.

Проект 111: `project111-data.js` содержит четыре варианта шелкографии (B1–B4, D1–D4, SH1–SH3, SHR) из предоставленного пользователем текста. Ссылки ведут в соответствующие разделы gifts.ru. Варианты B/SH/SHR сравниваются с общей шелкографией базы, D — с шелкотермотрансфером. Растр 20% указан только для B и D; ограничение Pantone ±15% не переносится на SHR.
